# Infernal Law

Прототип 0.0.2 для Godot 4.7.2: приёмная от первого лица в едином мрачном стиле. Интерфейс и сценарий на русском языке.

## Разработка по спецификации

Основной документ проекта — [CONCEPT.md](CONCEPT.md). Здесь описаны концепция, правила, основа 0.0.1, реализация 0.0.2 и следующие этапы. Перед изменением игры сначала сверяемся со спецификацией; новые требования и изменения поведения отражаем в ней вместе с кодом.

[AGENTS.md](AGENTS.md) задаёт этот порядок для ИИ-помощников. Полный план MVP в спецификации не означает, что все его возможности уже реализованы.

## Запуск

Импортируйте `project.godot` в Godot, откройте проект и нажмите F6 или F5.
На диске E также можно использовать `play.cmd` для игры и `edit.cmd` для редактора.

## Содержимое

- Одна смена: три написанных вручную дела.
- Досье, вопрос посетителю и проверка памяти.
- Два архивных запроса на смену.
- Справочник девяти кругов, выбор основания и подтверждение приговора.
- Проверка решения, доверие канцелярии и два результата смены.
- Автосохранение после приговора и архивного запроса в `user://shift.json`.
- Повторное прохождение через кнопку в конце смены.

## Управление

Нажмите «Следующий», чтобы вызвать грешника. После подхода закройте показания кнопкой или Esc. Откройте досье, допросите посетителя, затем выберите круг и основание через «Вынести приговор». Подтвердите печать и отправьте осуждённого к выходу. Очередь движется автоматически.

Папку, справочник, печать и звонок можно выбирать мышью прямо на столе; те же действия доступны нижними кнопками. Камера неподвижна. Читать можно без ограничения времени.

## Структура

- `game.gd` — состояние смены, экранные панели и сохранение.
- `reception_room.gd` — геометрия комнаты, персонажи, очередь, свет и выбор предметов.
- `case_data.gd` — тексты трёх дел и правила кругов.
- `main.gd` — совместимый вход для старых ссылок на скрипт.

Сохранение использует прежний каталог Godot `app_userdata/Канцелярия преисподней`, чтобы изменение названия окна не потеряло прохождение. Если сохранённая смена уже закончена, нажмите «Начать новую смену» на итоговом экране.

Это пространственный прототип: пока без 12 дел, разветвлённого сюжета, финального арта и звука. Персонажи перемещаются условно, без анимации шагов.

## Проверки

Из корня проекта в Git Bash:

```bash
/e/godot_v4.7.2/Godot_v4.7.2-stable_win64_console.exe --headless --path . --script res://tests/smoke.gd -- --test
/e/godot_v4.7.2/Godot_v4.7.2-stable_win64_console.exe --headless --path . --script res://tests/layout.gd -- --test
```

Тесты используют отдельный `test_shift.json` и не меняют игровое сохранение. Headless-проверки не заменяют оценку изображения и FPS в окне игры.
